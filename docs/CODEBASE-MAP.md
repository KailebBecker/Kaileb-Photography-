# Codebase Map (navigation index — source code is authoritative)

Purpose: find where things live without reading the repo. Reflects the site as of M1 (front-end hardening). Update only when file responsibilities or important relationships materially change — not for ordinary edits. Planned-but-nonexistent files (Worker, admin, image scripts) are in ARCHITECTURE.md, not here; add them when created.

## Shape
Plain static site: 6 HTML pages → one `styles/main.css` → one `scripts/main.js`. No build step, no CI, no deploy config. `package.json` is dev-tooling only (Playwright, axe, http-server): `npm test`, or `npm run serve` to browse at :4173.

## Shared page skeleton (duplicated in every HTML page — no templating)
Each page repeats: `<head>` (title, description, OG tags, canonical, inline SVG favicon, Google Fonts, `styles/main.css?v=N`), skip link, `.site-header` + nav (`#nav-toggle`, `#primary-nav`, `.header-cta`), `<main id="main">`, `.site-footer`, `<script src="scripts/main.js?v=N">`. **A change to nav/footer/head/category list must be made in all 6 pages**; `?v=` query strings are manual cache-busters (bump when CSS/JS change). Domain `www.kailebbeckerphotography.com` is hardcoded in canonicals/OG/sitemap/robots.

## Scripts
| Path | Responsibility | Key functions (all init on DOMContentLoaded, each guards for missing DOM) | Inspect when |
|---|---|---|---|
| `scripts/main.js` | Only JS file, shared by all pages. Loaded at end of body; inits run immediately at the bottom of the file, each in try/catch | `initNavToggle` (menu, aria-expanded, Escape) · `initTransparentHeaderOnScroll` · `initScrollLanding` (IntersectionObserver tracks current section → dots/`.active`; dots `scrollIntoView`; no wheel/key handlers) · `initTypewriterCaptions` · `initPhotoLightbox` (per-category prev/next, arrows, swipe, focus trap, `inert` background) · `initContactForm` (validation, min date in Arizona time, truthful unavailable message; M5 replacement point) · `initScrollReveal`. `enableCssEnhancements()` sets `html.js-enhanced`, the only thing that hides `.reveal`/`.typewriter` (progressive enhancement; skipped under reduced motion) | Any behavior change |

## Styles
`styles/main.css` (single file, ~1650 lines; `:root` tokens at top incl. palette `--color-accent` sage). Contrast uses `--color-accent-text` / `--color-accent-deep` (accessible shades; palette decision still open). Section headers to jump by (`grep -n "^/\* ---"`): Reset · Scroll reveal · Buttons & links · Pill badges · Header/nav (+ transparent/scrolled variants, mobile nav) · Hero (`.photo-hero`, grain, mobile overrides) · Sections · Services grid · Pricing cards · Callout · Teaser grid · Collections (native-scroll sections + per-collection background images + max-width 768 centered layout) · Gallery jump-nav · Photo grid (gallery, per-location subsections, rotation) · Lightbox (close/prev/next/status) · About · Contact (+ form notice/error/status states) · Footer · Page hero. Breakpoint 768px is the key mobile/desktop switch and is mirrored in JS (`window.innerWidth > 768`). `prefers-reduced-motion` blocks exist near reveal, collections, and photo grid. Inspect for any visual, touch-target, contrast, or palette work.

## SEO / crawl files
`sitemap.xml` (6 URLs, hardcoded domain, no lastmod) · `robots.txt` (allow all + sitemap) — edit when pages/domain change.

## Fonts, 404
`fonts/*.woff2` self-hosted latin-subset fonts, declared at the top of `styles/main.css` (pages preload Inter and Playfair); `404.html` is a self-contained page (no relative assets) copied to staging by the workflow.

## Images (do not enumerate)
**Sources** (never edited by tools): `source/<category>/*.jpg` (committed; today's already-downsized JPEGs, not true originals) and gitignored `originals/<category>/*` (true originals; wins when present). **Generated** (do not hand-edit; `npm run images`): `images/<category>/<Name>-<hash>-<width>.avif|jpg` and `images/manifest.json`. `images/portraits/*.svg` are placeholders (not processed), `images/og-image.png|svg` social card, `images/kaileb-portrait.svg` placeholder. Pages author `<picture data-photo="cars/Car1" data-preset="grid|teaser|hero|cover|cover-first"><img alt="…"></picture>`; `scripts/build-images.js` expands the rest (sources, srcset, sizes, width/height, loading, fetchpriority). Hero = `proposals/Proposal8`; collections backgrounds are `<img class="scroll-photo">`, not CSS backgrounds.

## Inquiry backend (`server/`, own package.json; Node >= 22)
`src/config.js` env config + production safety checks · `src/db.js` SQLite open + versioned migrations (`inquiries` table) · `src/validate.js` all server-side validation/normalisation (single source of truth for limits; client mirrors a subset) · `src/lifecycle.js` owner lifecycle state machine, double-booking guard, notes/audit events, delete, purge (explicit args) · `src/service.js` durable create (idempotency, per-email cap) + notification attempts/retry · `src/notify.js` Resend/dev/none notifiers + plain-text email builder · `src/app.js` Fastify app: CORS allowlist, origin check, rate limit, `POST /api/inquiries`, `GET /health` · `src/index.js` process start/sweeper/shutdown · `src/cli.js` owner CLI (list/show/accept/decline/confirm/cancel/complete/spam/note/delete/purge) · `src/availability/` **availability** (`engine.js` rules + blocks + sessions + external cache -> per-date answer, fail-safe rule, confirm-time guard; `google.js` Google free/busy behind the `getBusy()` interface; `sync.js` atomic busy-cache refresh; `oauth.js` + `src/calendar-auth.js` one-time authorisation; `time.js`/`intervals.js` Phoenix-time and interval math) · `src/cli-availability.js` owner commands (block/rules/setting/availability/calendar) · `GET /api/availability` in `src/app.js` · `src/backup.js` verified DB backup + `--verify FILE` · `deploy/` production templates for Ubuntu (env.example, `kaileb-inquiry.service`, backup `.service`+`.timer`, `nginx.conf.example` with `__API_HOSTNAME__` placeholder, `kaileb-inquiries` CLI wrapper) · `README.md` **the administrator's deployment/operations guide** (single handoff doc; dev notes at the end) · `test/` node:test API, lifecycle/CLI, backup-restore, `deploy.test.js` (templates consistent with code: env vars documented, paths/port/user agree, nginx limits/exposure, no tracked secrets) `availability.test.js`, `google.test.js` (incl. the privacy test that seeds private event strings and searches the whole database, API, CLI output and logs), `availability-api.test.js`, `calendar-auth.test.js`, `cli-availability.test.js`, and `security.test.js` (hostile input, rate/IP/proxy handling, Turnstile with a fake provider, log hygiene, real-process start-up checks). nginx behaviour itself is only checked by static assertions in-repo; see STATE.md for the manual nginx run. Browser side: `scripts/site-config.js` (per-environment `inquiryApiUrl`/`turnstileSiteKey`, empty in git, filled by the Pages workflow from repo variables) and `initContactForm` in `scripts/main.js`; tests `tests/inquiry.spec.js` (mocked API) and `tests/inquiry-e2e.spec.js` (real server).
